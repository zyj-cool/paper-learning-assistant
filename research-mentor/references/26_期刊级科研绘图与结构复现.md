用于科研论文中的代码原生图件：统计图、机制仿真图、多面板图、论文图结构复现和可复用绘图工程。目标是把“能看出结构”提升为“可投稿、可复核、可维护”的图件模板。

## 能力边界

使用本参考文件：

- 论文数据图、统计图、模型比较图、Kaplan-Meier、生存风险表、Bootstrap 区间、热图、聚类树、雷达图、点区间图、堆叠面积图、时序小多图。
- 用户要求 SVG/PDF/PNG、600dpi、Matplotlib、代码复现、synthetic/demo 数据、assumptions、manifest、自动质检。
- 用户给出论文图、图注、Deep Research 报告或提示词，要求按结构复现而不是复制像素。
- 用户给出 Visio `.vsdx` 工程图并要求检查、文本替换、期刊级升级或 PDF/SVG/PNG 批量导出时，联动 `28_Visio科研图编辑与MCP工作流.md`。

不要使用本参考文件抢占其他能力：

- 对话内交互演示、可调参数小工具、地图或即时可视化：使用 `visualize`。
- AI 照片、插画、封面、纹理、真实物体、背景替换、透明位图：使用 `imagegen`。
- PPT/slide deck 排版：使用 presentation 相关能力。
- 直接修改 Word/PDF 文件、批注、页面渲染：使用 documents/pdf 能力；本参考只负责图件和图注逻辑。

## 多面板结构复现经验

复杂论文 Fig. 1 或 6-10 个 panel 的总图，先做结构合同，再画内容：

1. 先固定整图比例、A-H panel bounding box、行高比例、列宽比例和最小 panel 间距，再往 panel 内填内容。
2. 每个 panel 内继续划分内部保留区：标题带、绘图区、图例带、colorbar 轨道、旋转标签轨道、脚注轨道。不要把 legend、colorbar 或长标签放进数据最密集区。
3. 第一轮目标是“无覆盖结构版”：文字不压图、legend 不压数据、colorbar 不贴主图、panel 字母不压标题、旋转标签不越界、脚注不贴底部 panel。
4. 第二轮再做“有效绘图区放大与视觉密度校正”：压缩无效白边，增加 panel 内绘图区占比，放大点云/热图/曲线/机制图元，收紧但不取消层级留白。不要通过继续缩小字体来换密度。
5. 调密度时优先级：改画布有效区和 panel 比例；改内部 axes 相对位置；把图例放进本 panel 的保留条；减少非必要 tick 数量；缩短标签；最后才轻微改点径/线宽。不要低于任务要求的最小字号。
6. 对 UMAP/t-SNE 等点云图，使用同一坐标只改颜色映射；放大时优先增加点数、点云 axes 占比和点径，不要让图例轴与点云 axes 相交。
7. 对热图，增加横向/纵向采样密度让色带连续；基因名和细胞类型标签单独留轨道；长细胞类型可用期刊常见缩写，但必须在数据口径说明中保留完整含义。
8. 对 alluvial、phase strip、cluster strip 等窄桥结构，使用多条半透明细流带和明确方向箭头；不要用一条折线替代结构。
9. 对 2×3 small multiples，保留统一标题带、共享 x 轴语义、底部图例带；必要时只保留 0/中点/终点 tick，避免底部 tick 伸入图例。
10. 对概念总结面板，四阶段文本、散点小图和楔形演化带要等基线排列；底部 legend 与楔形带必须分轨道。

程序结构建议：

- 用 `build_panel_layout()` 返回固定 bbox 字典，不在各 panel 函数里临时决定全局布局。
- 用 `subax(fig, panel, rel, role)` 在 panel 内创建 axes，并标记 `role="plot" | "legend" | "colorbar" | "decor"`。
- 用 `panel_label()` 单独放置面板字母，并标记为 panel label，避免和普通文本混检。
- 用 `validate_text_bboxes()` 收集所有文本、axes、legend、colorbar、panel 的 renderer bbox。
- 至少检查 `text outside canvas/panel`、`axes overlap`、`legend/colorbar outside panel`、`legend/colorbar vs plot area`、`text vs text`、`text vs legend/colorbar`、`footnote vs bottom panel`。
- 输出 `fig_overlap_debug.png`：红框标 panel，蓝框标 legend/标题区，绿框标 colorbar，冲突区域半透明红色；无冲突时标注 `No obvious overlap detected`。
- 可加入有限安全迭代：若 bbox 检查失败，自动增加局部保留轨道或调整 row ratio；不要用无限循环或盲目缩字号。

## 数据生成原则

机制模拟不能是“简单线性函数 + 随机噪声”。按学科图形语法生成：

- 训练曲线：分阶段提升、平台、相关波动和递减波动幅度。
- 临床 KM：先生成患者级事件时间、删失时间和 event indicator，再计算 Kaplan-Meier。
- 纵向临床试验：快速变化期、慢变化期、平台期、访视点误差棒和终点统计分离。
- 排名点区间图：每组不同中位数、不同置信区间宽度、合理竞争群。
- 堆叠面积图：类别增长速率不同，交点数值求解，不手写死。
- 文本小多图：每个语料库不同峰值、转折、斜率、结构突变和置信区间。
- 聚类图：从国家/样本特征矩阵计算 linkage，不手工画树。

## 典型图形路由

- 气象/模型技能图：折线 + 相对差值 + ACC + 多变量热图，发散色标以 0 为中心。
- 强化学习训练图：Elo、预测准确率、MSE 三联图，共享时间轴，不用双 y 轴。
- 医学生存图：2×2 Kaplan-Meier + 风险人数表，风险人数从患者数据动态计算。
- 肥胖/药物纵向试验图：趋势图 + 终点柱图，观察均值和确认性终点分开。
- 结构生物排名图：横向点区间图，中位数排序，突出主方法，其他方法灰色。
- 环境存量图：堆叠面积 + 参照曲线 + 不确定性带 + 数值求解交点。
- 数字人文小多图：4×4 small multiples，行列共享轴规则明确，原始趋势 + 平滑趋势 + CI。
- 计算社会科学聚类图：树状图 + 雷达画像；增强版可用点图 + bootstrap CI 替代雷达。

## 导出与质检

每张正式图输出：

- SVG：文本保持可编辑。
- PDF：嵌入 TrueType 字体，避免全部文字转路径。
- PNG：600 dpi，白底，不透明。
- Preview：按实际宽度预览，并生成 50% 缩放预览。
- Visio `.vsdx`：保留原始文件，输出编辑副本；必要时导出 PDF、逐页 SVG、PNG/EMF，并记录文件级 XML 修改或 Visio COM 原生导出的处理方式。

自动检查至少覆盖：

- 目标画布尺寸和 600 dpi 像素宽度。
- 背景白色、无意外透明。
- 字号不低于任务设定的最小字号；若用户允许极小注释，最低仍要显式检查并报告。
- 无调试标题、文件名、`simulated`、`structural reproduction` 等正式稿禁词。
- 面板标号齐全。
- 色条、图例、风险表、误差棒和注释不裁切、不遮挡核心数据。
- 对结构复现草图，额外输出 panel bounds 图、preview comparison 图和 overlap debug 图。
- validation JSON 至少报告 `warnings`、`min_font_pt`、`panel_bounds`、`overlap_warning_count`、`overlap_debug_regions`；最终交付前应达到 `warnings: []`，除非用户明确接受残余风险。
